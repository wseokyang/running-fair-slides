# Learning Voyage

`index.html`을 브라우저에서 열면 전체 목록을 볼 수 있습니다. `slide-01.html`부터 `slide-08.html`까지 각 페이지를 직접 열 수도 있습니다. 서버나 빌드 설치는 필요 없습니다. 공유할 때는 assets 폴더를 함께 전달하세요.

- 좌우 방향키 / PageUp·PageDown / Space: 페이지 이동
- 숫자 1–8: 해당 슬라이드 이동
- N: 발표 노트, F: 전체 화면, Esc: 닫기
- 브라우저 인쇄: 현재 슬라이드를 16:9 가로 페이지로 인쇄 (배경 그래픽 켜기 권장)
- 작은 화면: 읽기 편한 세로 레이아웃으로 전환

원문 스토리보드는 source/conversation.txt에 보관했습니다. 수치는 공유 대화에서 옮긴 값으로 별도 검증되지 않았습니다. 어학 17%의 산식·기간, 최고 수준 비교 기준과 각 지표의 대상 기간은 발표 전에 확인하세요. 논문 증가와 Q-BRIDGE 사이의 단독 인과관계는 주장하지 않습니다. 7장은 원문 방향을 유지하되 확인된 실행·과제화·역량 지표를 사업의 금전적 효과와 구분했습니다.

원본 design.md는 수정 없이 저장했습니다. 웹 발표에 맞게 큰 타이포그래피, 흰색 중심 배경, 단일 파란색 강조, 그림자·장식 그라데이션 없는 화면을 적용했습니다. 항로·범선·지식 순환 도식은 SVG/CSS로 직접 구성했습니다. SF Pro는 시스템에 있을 때 사용하며 한국어는 설치된 시스템 글꼴로 표시합니다.
