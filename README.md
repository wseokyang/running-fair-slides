# Learning Voyage

## 실제 발표

`index.html`에서 **클리커 발표 시작**을 선택하거나 `present.html`을 직접 여세요. **전체 화면 시작**을 한 번 누른 뒤에는 클리커의 앞/뒤 버튼만으로 진행할 수 있습니다. 외부 서버·인터넷·빌드 설치가 필요 없습니다. 배포 시 HTML과 assets 폴더를 함께 전달하세요.

- `PageDown` / `→` / `↓`: 다음 요소 공개 → 마지막 공개 후 다음 슬라이드
- `PageUp` / `←` / `↑`: 이전 공개 단계 → 첫 단계에서 이전 슬라이드의 완성 화면
- Space / Enter: 다음 단계 (버튼에 키보드 포커스가 있으면 해당 버튼 실행)
- `F` / `F5`: 전체 화면 전환, `Esc`: 전체 화면·노트·가림 화면 닫기
- `N`: 발표 노트. 노트가 열린 상태에서 다음 버튼을 누르면 노트만 닫습니다.
- `B` / `.`: 검정 가림 화면, `W` / `,`: 흰색 가림 화면. 다음 버튼으로 가림 해제 후 이어서 진행합니다.
- `1`–`8`: 해당 슬라이드 첫 단계로 이동, Home: 처음, End: 마지막 완성 화면
- 클릭·터치로도 다음 단계 진행. 제어 버튼은 전체 화면에서 1.8초 후 자동으로 숨겨집니다.
- 키를 길게 눌러 발생하는 반복 입력은 무시합니다. 모든 효과는 클리커 입력으로 진행하며 자동 넘김은 없습니다.

발표 모드는 한 HTML 문서에서 동작하므로 장이 바뀌어도 전체 화면이 유지됩니다. 새로고침하면 URL에 표시된 장과 단계가 복원됩니다. 일반적인 키보드 방식 클리커를 지원하며 실제 기기의 키 매핑은 발표 전에 확인하세요. 전용 앱에서만 동작하는 독자 프로토콜 클리커는 브라우저에서 직접 제어할 수 없습니다.

## 화면 및 개별 파일

- **모든 슬라이드 1440 × 810 / 16:9 고정**. 모바일·4:3 프로젝터에서도 잘라내거나 재배치하지 않고 비율대로 축소합니다. 남는 영역은 여백으로 표시합니다.
- 흰색 슬라이드 배경, 시스템 글꼴, 단일 파란색 포인트.
- `slide-01.html`–`slide-08.html`: 각 장의 완성 화면. 개별 페이지의 **발표 모드**로 해당 장의 클리커 발표를 시작할 수 있습니다.
- 개별 슬라이드를 직접 넘기는 경우에는 문서가 바뀌므로 실제 발표에는 반드시 `present.html`을 사용하세요.
- 발표 화면 인쇄: 숨겨진 단계를 모두 공개하여 전체 8장 인쇄. 개별 HTML 인쇄: 해당 장만 인쇄. 배경 그래픽 켜기 권장.
- OS의 동작 줄이기 설정에서는 전환 애니메이션을 생략합니다.

## 발표 단계

| 장 | 클리커로 공개되는 내용 |
|---|---|
| 1 | 목적지 → 4대 핵심역량 |
| 2 | 하나로 연결된 학습체계 이미지 → Learn·Share·Perform 운영 → 조직의 연결 역할 |
| 3 | 실행을 만든 운영 과정과 부문 비교 → 1.83배·3.4%p 및 중간 실행률 |
| 4 | Knowledge Loop 이미지 → 팀장 매회 참석·팀원 참여 → 논문 변화 |
| 5 | 업무과제 40개 → 그중 10개 팀 과제 강조 → 실행 파이프라인 |
| 6 | 글로벌 학습 생태계 이미지 → 17% 및 총괄 최고 상승률 |
| 7 | 실행·지식의 조직 변화 → 업무과제·글로벌 역량 → DS부문 인정 |
| 8 | DS부문 우수사례 선정·인터뷰 → 공유 요청받은 세 가지 운영 방식 |

## 수정 및 검증

개별 HTML이 내용 원본입니다. 수정한 후 `python3 scripts/build-deck.py`를 실행하면 통합 발표 화면이 갱신됩니다. 공통 디자인과 동작은 `assets/style.css`, `assets/slides.js`에서 수정합니다.

브라우저 회귀 검증: `PLAYWRIGHT_MODULE=/path/to/@playwright/test node tests/presentation.cjs`. 8장의 모든 공개 단계, 전체 화면 유지, 역방향 이동, 키 반복 방지, 노트와 가림 화면, 새로고침 복원, 다양한 화면의 16:9 비율 및 이미지 로딩을 검증합니다. 실제 물리 클리커는 테스트하지 않았습니다.

## 생성 이미지

내장 **image_gen** 도구로 만든 `assets/voyage-hero.png`와 `assets/voyage-fleet.png`를 첫 장과 마지막 장에 사용합니다. 흰색 세라믹 돛·실버 선체·파란 항로의 고급 제품 사진 스타일이며, 정확한 생성 프롬프트와 도구 방식은 `source/image-prompts.json`에 보관했습니다. 수치·라벨은 이미지에 넣지 않고 수정 가능한 HTML로 유지합니다. 2·4·5·6장의 구조 도표도 내장 image_gen으로 생성한 PNG 이미지입니다. 원본 8장 스토리보드의 남색·청록 노드와 화살표를 참고했으며, 과제 40개 중 10개를 강조하는 매트릭스와 정확한 수치 비교 차트는 HTML/CSS로 유지했습니다. 이미지 도표의 문구를 바꾸려면 해당 PNG를 다시 생성해야 합니다. 도표별 경로와 정확한 생성 프롬프트는 `source/diagram-prompts.json`에 있습니다.

원본 design.md는 수정 없이 저장했습니다. 웹 발표에 맞게 큰 타이포그래피, 흰색 중심 배경, 단일 파란색 강조, 그림자·장식 그라데이션 없는 화면을 적용했습니다. 항해 이미지와 구조 도표는 생성 이미지로, 수치·비교·과제 강조는 HTML/CSS로 구성했습니다. SF Pro는 시스템에 있을 때 사용하며 한국어는 설치된 시스템 글꼴로 표시합니다.

## 발표 주장의 기준

핵심은 몇 개의 우수 수치가 아니라 **리더십 → 구성원의 실행 → 지식 순환 → 현업 적용 → DS부문 인정**으로 이어지는 조직의 운영 수준입니다.

- 부문 평균을 넘는 활용률은 실행 환경의 근거입니다.
- 팀장 매회 참석, 참여와 논문 변화는 리더 참여와 지식 축적의 근거입니다.
- AI 과제 전환과 총괄 최고 어학 상승률은 업무 연결과 조직 역량 강화의 근거입니다.
- DS부문 우수사례 선정·인터뷰는 운영 모델 전체의 확산 가치를 설명하는 근거입니다.

`source/strength-evidence.md`에 원문 발췌, 계산식, 비교 범위를 보관했습니다. 전체 지표에서 품질팀이 1위라는 확인되지 않은 주장은 넣지 않았습니다. ‘총괄 내 최고’는 원문이 명시한 **어학역량 상승률**에 한정됩니다.
